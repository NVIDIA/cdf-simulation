# CDF capability matrix

Generated from registered `cdf.domains` plugins (`python -m cdf.capabilities --domain pcb-aoi > cdf/CAPABILITIES.md`) — do not edit by hand; unit tests enforce freshness and binding validity.

Five surfaces per capability: YAML config, Python API (`cdf`), skill intent (natural language), preview guidance, and the repository documentation that defines the behavior. Batch execution is authoritative for rendered datasets.
