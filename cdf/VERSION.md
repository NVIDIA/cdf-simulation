# CDF API version

Current API version: `1.0.0`
Current API status: `released`

This is the authoritative current version of the CDF authoring API. YAML
JobConfig documents declare the API version they target, and their accepted
structure and interpretation are defined by that API contract.

The 1.0.0 contract is published. Subsequent contract changes require semantic
version increments. Version history and compatibility policy are recorded in
[`API_CHANGELOG.md`](API_CHANGELOG.md).
