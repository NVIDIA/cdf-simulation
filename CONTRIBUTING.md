# Contributing to CDF Simulation

We welcome contributions to
[`NVIDIA/cdf-simulation`](https://github.com/NVIDIA/cdf-simulation).

## Submitting a contribution

1. Fork the repository and create a focused branch for your change.
2. Follow the setup and development guidance in [`README.md`](README.md).
3. Run the tests relevant to your change and include the commands and results
   in your pull request.
4. Sign off every commit as described below.
5. Open a pull request describing the change and why it is needed.

## Signing your work

All contributions must be signed off to certify that the contributor has the
right to submit the work under the repository's license. Commits without a
valid `Signed-off-by` line cannot be accepted.

Use the `--signoff` (or `-s`) option when committing:

```bash
git commit -s -m "Describe the change"
```

This appends a line like the following to the commit message:

```text
Signed-off-by: Your Name <your.email@example.com>
```

